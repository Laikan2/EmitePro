# Emite Pro

Aplicativo para Windows com cadastro de produtos e emissão de NF-e pela Focus NFe.

## Atualizações

O Emite Pro procura novas versões automaticamente ao entrar. Para verificar manualmente, abra **Preferências → Atualizações do programa → Verificar atualizações**.

Quando aparecer uma versão nova, salve seus rascunhos e clique em **Atualizar programa → Baixar e instalar**. O programa valida o download, cria uma cópia de segurança, instala a atualização e reabre.

Os produtos, clientes, notas e configurações ficam no computador e são preservados. Para uma primeira instalação, use o instalador disponível em [Releases](https://github.com/Laikan2/EmitePro/releases/latest).

Este repositório distribui os instaladores, o manifesto de atualização assinado e os arquivos públicos de verificação.
